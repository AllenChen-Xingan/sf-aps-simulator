Funding and coordination pathways for accessible pedestrian signals in San Francisco: an agent-based model

Replication package · Allen Chen · 2026

This package contains the code, documentation, input data and results of an agent-based model (ABM) that compares how San Francisco could convert pending requests for accessible pedestrian signals (APS) into funded installations. The model follows the 76 crossings pending in June 2026, and new requests, month by month for ten years. Seven pathways (current practice and six alternatives) are compared under six alternative explanations of the observed stall, across 1,000 combinations of uncertain parameters with 20 replicates each. It is a scenario comparison under deep uncertainty, not a forecast.

The documentation follows the ODD protocol, second update (Grimm et al., 2020), with the ODD+D extension for human decision-making (Müller et al., 2013); the TRACE framework for documenting development, testing and analysis (Grimm et al., 2014); and the STRESS-ABS reporting checklist (Monks et al., 2019).

2. Reproducing the results

Requirements: Python (version in environment/python-version.txt), a POSIX shell, and about 4.5 hours on 8 CPU cores for the full set of experiments. From the replication/ folder:

./reproduce.sh --quick      # environment, checksums, self-tests, baseline check and one sensitivity cell
./reproduce.sh              # all main experiments, compared field by field with results/
./reproduce.sh --e4-full    # additionally reruns the complete sensitivity analysis

The script builds a fresh virtual environment from the pinned dependencies, runs each experiment in a working copy and compares every regenerated summary with the files in results/. Details and measured run times are in docs/reproducibility.md.
