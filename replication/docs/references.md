# References

## 1. Scope and conventions

This list contains every work cited in the replication package: the model documentation (ODD+D description, TRACE document, STRESS-ABS checklist, parameter table, actors and evidence) and the code comments that cite sources. Entries follow APA 7.

- Works by the same author in the same year carry letter suffixes (2026a, 2026b, ...) assigned in alphabetical order of title, as APA 7 prescribes. Package files use the in-text forms listed in Section 2.
- Undated web pages and data sets are cited as "n.d." with suffixes where needed; the retrieval date is the date the copy used to build the model inputs was taken.
- The author's interview with SFMTA staff is cited in text only, as "SFMTA staff, personal communication, 2026". APA 7 does not list personal communications in the reference list, and the package does not identify the interviewee.
- Digital object identifiers (DOIs) of all journal articles and books in Section 3 were checked against the Crossref REST API (api.crossref.org) on 28 October 2026. All resolved and matched the title, journal, volume, issue and pages given here; the results are summarised in Section 4.
- Page, section, question and slide numbers are given at the point of citation, not in the entries.
